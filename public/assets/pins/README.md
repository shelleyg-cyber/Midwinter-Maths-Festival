# Map pin artwork

Teardrop map-marker images shown on the landing-page world map, one per destination.
Split the combined pin sheet into eight separate files and drop them here with these
exact names. **Save them as PNG with a transparent background** so only the teardrop
shows over the map (no white box around it).

| File | Destination | Icon on the pin |
|------|-------------|-----------------|
| `pin-australia.png` | Australia | Radial dots (dot-painting) |
| `pin-america.png` | America | Ruler, "ft ↔ cm" |
| `pin-south-asia.png` | South Asia | Floral rosette |
| `pin-southeast-asia.png` | Southeast Asia | Crescent moon + grid of squares |
| `pin-east-central-africa.png` | East & Central Africa | Tally marks |
| `pin-southern-africa.png` | Southern Africa | Musical note |
| `pin-middle-east-north-africa.png` | Middle East & North Africa | Eight-point star |
| `pin-europe.png` | Europe | Bridge over water |

Until a file is present, that pin falls back to the original parchment-ticket pill
(coloured dot + name) automatically — nothing breaks while you upload them.
